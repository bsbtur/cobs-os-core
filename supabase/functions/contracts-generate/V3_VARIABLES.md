# CIOSP-2027/V3 generated variables

The immutable snapshot v2 exposes `contract_variables` for the renderer:

- contract_date
- customer identity/contact/address fields
- operation identity, dates and destination
- order_id / reservation_id
- currency
- grand_total_formatted
- grand_total_in_words
- payment_plan_display
- package_name
- order_items
- offer_snapshot
- privacy_policy_version (optional)

Raw `grand_total_minor` remains in the canonical order snapshot for accounting/audit but is not the customer-facing amount variable.
