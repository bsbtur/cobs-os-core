# Assistant Router monetary regression

For BRL, COBS financial values must be presented using the unit semantics supplied by the trusted context. The validated QA case is R$ 2.490,00 paid + R$ 7.500,00 balance = R$ 9.990,00 total. The Router must not render these as R$ 249,00 / R$ 750,00 / R$ 999,00.
