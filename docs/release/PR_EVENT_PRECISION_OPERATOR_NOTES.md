# Event schedule precision operator control — integration gate

This branch introduces the authenticated operator control component for event `schedule_precision`.

The component calls only the approved `set_event_schedule_precision` RPC with:

- `_event_id`
- `_schedule_precision` (`datetime` or `date_only`)
- `_idempotency_key` generated by the existing W07 helper

It does not mutate event timestamps or lifecycle state directly.

## Gate before merge

The component must be wired into the existing operator event header before this PR can leave draft status. After wiring, require Quality Gate, Vercel preview validation and authenticated operator QA. Do not merge while the component is orphaned.
